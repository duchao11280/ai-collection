# #7. Reinforcement Learning

Reinforcement Learning là một kỹ thuật học máy trong đó một agent học cách hành động trong một môi trường để tối đa hóa tổng phần thưởng mà nó nhận được. Quá trình này liên quan đến việc agent thực hiện các hành động, nhận phản hồi từ môi trường dưới dạng phần thưởng hoặc hình phạt, và điều chỉnh hành động của mình để cải thiện hiệu suất.

## Key concepts:

* Agent: Thực thể đưa ra quyết định và học hỏi từ môi trường.
* Environment: Thế giới mà agent tương tác và khám phá.
* State (Trạng thái): Tình huống hiện tại của môi trường mà agent có thể quan sát.
* Action (Hành động): Các quyết định hoặc động thái mà agent có thể thực hiện.
* Reward (Phần thưởng): Phản hồi từ môi trường mà agent nhận được sau khi thực hiện hành động, đánh giá mức độ tốt hay xấu của hành động đó.
* Policy (Chính sách): Chiến lược mà agent sử dụng để quyết định hành động dựa trên trạng thái hiện tại.
* Value Function (Hàm giá trị): Hàm ước lượng giá trị dự kiến của các trạng thái hoặc trạng thái-hành động, giúp agent đánh giá lợi ích dài hạn của các hành động.
* Q-Function: Hàm giá trị cụ thể đánh giá mức độ tốt của một hành động tại một trạng thái cụ thể.
